# Mission 2 — 신고자 / 119대원 발화 분류

## 1. Mission 2 한눈에 보기

통화에서 잘라낸 **한 사람의 한 발화**를 `speaker=0`(119대원) 또는 `speaker=1`(신고자)로 분류한다. 평가 지표는 **발화 단위 Accuracy**다. 클래스별 정답률은 실제 해당 클래스 중 맞힌 비율인 **Recall**로 별도 확인한다.

현재 보고된 최고 결과는 **Small-stem ResNet18과 ResNet34의 신고자 확률을 50:50으로 결합하고 임계값 0.5를 적용한 Validation Accuracy 91.419%**다. 단일 모델의 성능이나 비공개 Test 성능이 아니다.

**2026-10-06 기준 유지할 모델은 이 ResNet18+34 결합 모델이다.** 대원 가중치 실험까지 전체 검증으로 비교했지만 이를 넘지 못했다. 따라서 최신 실험 폴더가 아니라 아래 두 체크포인트를 사용한다.

| 구성 | 보관 폴더 | 역할 |
|---|---|---|
| ResNet18 small-stem | `mission02_next_best/best_model.pt` | 신고자 확률의 50% |
| ResNet34 small-stem | `mission02_resnet34_v3/best_model.pt` | 신고자 확률의 50% |
| 공통 입력 | `first_plus_whole`, `[1,64,48]` | 앞 1.5초 + 전체 발화 요약 |
| 판정 | 평균 확률 ≥ 0.5이면 신고자, 미만이면 대원 | 전체 91.419%, 대원 86.92%, 신고자 95.59% |

가중치 실험 모델, WavLM, Dual-view 모델은 이 구성에 포함하지 않는다. 최신 유지 모델의 상세 집계는 [91.419% 모델 결과 보고서](results/resnet_ensemble_fixed_05.md)를 참고한다.

```text
WAV + JSON의 startAt/endAt
    → 한 발화 구간 자르기
    → 앞 1.5초 log-Mel + 발화 전체 요약 log-Mel
    → [64,48] 특징
    → Small-stem ResNet18 / ResNet34
    → 신고자 확률 평균 → threshold 0.5 → speaker 0/1
```

`speaker`는 학습·평가 정답에만 사용한다. 전사 텍스트, 발화 순서, 파일명, 주소는 분류기 입력으로 사용하지 않는다. 경로와 발화 ID는 파일 찾기와 결과 매칭에만 사용한다.

> 범위: 2026-10-06까지 공유된 실험 결과를 반영했다. `smallstem_resnet18/results/`는 초기 실험 원본 기록이며, 해당 폴더의 학습·평가·추론 코드는 이번에 0.5 고정으로 수정했다. 후속 결합 결과는 제공된 Colab 로그에 근거한다. 후속 체크포인트·결합 코드 전체를 공개하거나 전체 데이터를 독립 재평가한 것은 아니다. Drive의 기존 ZIP과 실행 중인 Colab 코드는 이 GitHub 변경으로 자동 갱신되지 않는다.

## 2. 데이터와 전처리

### 2.1 데이터 구성

서울 지역 공통 검사·매니페스트 생성 파이프라인에서 확인한 수치다.

| 항목 | Training | 공식 Validation |
|---|---:|---:|
| WAV / JSON 매칭 통화 | 29,200 / 29,200 | 3,640 / 3,640 |
| 발화 | 889,358 | 111,947 |
| 119대원 (`speaker=0`) | 427,161 | 53,845 |
| 신고자 (`speaker=1`) | 462,197 | 58,102 |

검사한 WAV는 **8kHz, mono, 16-bit PCM**이었다. 사용한 데이터 복사본의 검사에서 WAV/JSON 누락·손상 0건을 기록했다. 상세 집계는 [EDA 보고서](eda/REPORT.md)를 참고한다. 공식 Training/Validation 분리를 유지하며, 같은 통화의 발화를 임의로 양쪽에 나눠 넣지 않는다. 다만 동일 인물이 서로 다른 통화로 두 split에 존재하는지는 확인하지 못했다.

### 2.2 현재 주력 전처리: `first_plus_whole`

**한 발화의 앞 1.5초와 발화 전체의 요약을 함께 사용한다.** 전체 통화가 아니라 `startAt`·`endAt`으로 자른 해당 발화만 처리한다.

1. **발화 자르기**: JSON의 시작·종료 시각(ms)에 해당하는 WAV 구간을 가져온다.
2. **앞부분 특징**: 앞 1.5초를 사용한다. 더 짧으면 뒤에 0을 채우는 zero-padding을 적용한다. 64개 Mel 주파수 대역의 log-Mel 특징 `[64,24]`를 만든다.
3. **전체 발화 특징**: 1.5초보다 긴 발화는 전체 구간의 log-Mel을 만든 뒤, 시간축을 24개 구간으로 나눠 각 구간의 특징을 평균한다. 결과는 `[64,24]`다. 1.5초 이하이면 앞부분 특징을 그대로 재사용한다.
4. **결합**: 두 특징을 시간축 방향으로 붙여 `[64,48]`로 만든다. 앞 24프레임과 뒤 24프레임은 서로 다른 시간 범위다. **48프레임이 일정한 시간 간격으로 연속된 음성은 아니다.**
5. **정규화·저장**: log-Mel을 `clip((mel + 80) / 80, 0, 1)`로 변환한다. 전체 발화 평균도 이 정규화된 특징에 적용한다. 최종 특징은 `round(feature * 255)`로 `uint8` 저장하고, 학습 시 float32로 읽어 255로 나눈다.

예를 들어 4초 발화는 **앞 1.5초 특징 + 4초 전체의 압축된 특징**으로 표현한다. 뒤쪽 음성을 완전히 버리지는 않지만, 시간축 평균으로 압축하면서 세부적인 변화는 손실될 수 있다.

로그 멜 스펙트로그램은 시간에 따른 주파수 대역별 에너지 분포이며, 음성을 글자로 변환한 것이 아니다. 특징을 미리 계산한 이유는 원본 WAV 전체를 Colab에 올리지 않고 학습하기 위해서다. 현재 특징 파일은 `mission02_features_full.zip`이며, 새로운 음성 추론에는 동일한 전처리가 필요하다.

### 2.3 전처리 실험 구분

| 이름 | 특징 | 사용 범위 |
|---|---|---|
| `first_1p5` | 앞 1.5초만, `[64,24]`, float16 | 초기 90.25% 실험 |
| **`first_plus_whole`** | 앞 1.5초 + 전체 발화 요약, `[64,48]`, uint8 | 현재 최고 모델; 완료된 대원 가중치 실험에서도 사용 |
| `three_window` | 앞·중간·끝에서 1.5초씩 선택, 각각 16프레임으로 요약·결합 | 별도 비교 실험; 현재 최고 모델에는 미사용 |

현재 방식은 **sliding window가 아니다**. 일정 간격으로 창을 계속 이동시키지 않는다. 공통 검사·구간 자르기·Mel 추출 함수를 활용했지만, 두 뷰 결합과 uint8 저장은 Mission 2 후속 실험에서 추가했다. 모든 후속 전처리가 공통 GitHub 명령 그대로였다고 설명하지 않는다.

## 3. 왜 이미지 분류에 쓰이는 ResNet을 선택했는가?

ResNet을 사용해도 작업 자체는 **음성 분류**다. 음성을 시간×주파수의 2차원 특징으로 표현하고 CNN으로 분류한 것이다.

- log-Mel의 국소적인 시간·주파수 패턴을 2차원 합성곱으로 학습할 수 있다.
- ResNet의 잔차 연결은 깊은 신경망의 학습을 돕는다.
- ImageNet 사전학습 가중치를 초기값으로 활용한 뒤 음성 데이터로 전체 모델을 학습한다. 사전학습의 효과 자체를 따로 입증한 실험은 아니다.
- 작은 Mel 입력을 초기에 과도하게 축소하지 않도록 **small-stem** 구조를 적용했다.

정확한 설명은 **“전처리를 ResNet 입력에 맞춰 설계했고 실험에서 유효한 결과를 얻었다”**이다. “음성 전용 모델보다 이미지 모델이 본질적으로 우수하다”는 결론은 내리지 않는다.

### WavLM과 비교할 때의 주의점

WavLM에는 동일한 Mel 특징을 넣지 않았다. 발화의 앞 최대 3초 파형을 8kHz에서 16kHz로 리샘플링하고, 고정된 WavLM hidden state의 평균·표준편차 임베딩을 추출했다. 4·8·12층과 LightGBM/로지스틱 회귀를 비교했으며 **WavLM 자체는 미세조정하지 않았다**.

| 조건 | 주력 ResNet | WavLM 예비 실험 |
|---|---|---|
| 입력 | 앞 1.5초 + 전체 발화 요약 Mel | 앞 최대 3초 파형 |
| 학습 발화 수 | 889,358 | 10,000 → 50,000 |
| 학습 대상 | ResNet 전체 | 고정 임베딩 위의 분류기만 |
| 검증 | 전체 111,947개 | 그중 동일한 2,000개 표본 |

따라서 WavLM 예비 결과가 낮았다고 해서 ResNet이 모델 구조상 더 적합하다고 확정할 수 없다. 다른 실험자의 WavLM 결과와 비교하려면 학습량, 입력 길이, 사용 층, 분류기, fine-tuning 여부, split을 확인해야 한다. 현재 ResNet을 선택한 이유는 **확보한 전체 검증 성능과 실행 가능한 파이프라인**에 근거한다.

## 4. 모델 구조와 학습

### 4.1 Small-stem ResNet18 / ResNet34

```text
[B,1,64,48] log-Mel
    → 같은 Mel을 3채널로 반복 + ImageNet 채널별 정규화
    → 3×3 convolution, stride 1 + BatchNorm + ReLU
    → 초기 max-pooling 생략
    → 4개 residual stage
    → global average pooling
    → Dropout + Linear(512 → 2)
    → softmax: 대원/신고자 확률
```

3채널 반복은 새 음성 정보를 만드는 것이 아니라 backbone 입력 형식에 맞추는 처리다. ResNet18의 residual block 수는 `[2,2,2,2]`, ResNet34는 `[3,4,6,3]`이다. 일반 ResNet의 `7×7, stride=2` stem 대신 `3×3, stride=1`을 사용하고 초기 max-pooling을 제거했다. ImageNet 초기화 시 기존 7×7 stem 가중치를 3×3으로 축소해 사용한다.

AdamW, cosine 학습률 조절, early stopping을 사용하고 실험에 따라 SpecAugment, Mixup, label smoothing을 적용했다. 수정된 학습 코드는 Validation Accuracy@0.5로 epoch를 선택하며 임계값을 탐색하지 않는다. 과거 실험은 임계값 튜닝을 사용했으며, 그 기록은 과거 기록으로만 보존한다.

### 4.2 현재 최고 결합 모델

동일한 `first_plus_whole` 특징을 두 모델에 입력하고 **신고자 확률**을 평균한다.

```python
p_caller = 0.5 * p_resnet18 + 0.5 * p_resnet34
speaker = 1 if p_caller >= 0.5 else 0
```

모델 가중치 평균이 아니므로 추론에 두 모델이 모두 필요하다. **단독 모델과 결합 모델 모두 최종 임계값은 0.5로 고정**한다. 체크포인트에 남은 과거 튜닝 임계값은 사용하지 않는다.

## 5. 성능

### 5.1 전체 Validation — 111,947개

| 실험 | 전처리 / 판정 | Accuracy |
|---|---|---:|
| 초기 Small-stem ResNet18 | `first_1p5`, threshold 0.5 | 90.139977% |
| 기존 단독 ResNet18 | `first_plus_whole`, threshold 0.5 | 91.105612% |
| 증강 없는 추가 미세조정 ResNet18 | `first_plus_whole`, threshold 0.5 | 91.043976% |
| ResNet34 | `first_plus_whole`, threshold 0.5 | 91.029684% |
| **기존 ResNet18 + ResNet34** | **확률 50:50, threshold 0.5** | **91.419154%** |

모두 기존 체크포인트의 **0.5 판정 결과**이며 후속 수치는 공유된 Colab 평가 출력 기준이다. 과거 0.52에서의 91.437%는 제출 기준 성능에서 제외한다. 체크포인트 자체는 과거 튜닝 점수로 epoch를 선택한 이력이 있다. 이번 수정이 고정 0.5 기준 재학습 또는 체크포인트 재선택 완료를 의미하지 않으며, 기존 선택 이력의 허용 여부는 주최 측 확인이 필요하다. 여러 조건이 달라져 성능 차이를 전처리 하나의 효과로 단정하지 않는다.

### 5.2 최고 결합 모델의 클래스별 결과

| 실제 클래스 | 정답 / 전체 | 클래스별 Recall |
|---|---:|---:|
| 119대원 | 46,804 / 53,845 | **86.92%** |
| 신고자 | 55,537 / 58,102 | **95.59%** |
| 전체 | 102,341 / 111,947 | **Accuracy 91.419%** |

혼동행렬은 실제 행·예측 열, 순서 `[119대원, 신고자]` 기준이다.

| 실제 ＼ 예측 | 119대원 | 신고자 |
|---|---:|---:|
| 119대원 | 46,804 | 7,041 |
| 신고자 | 2,565 | 55,537 |

클래스별 정답률은 Precision이나 F1이 아니라 **Recall**이다. 현재 대원 발화를 신고자로 오인하는 오류가 더 많다.

### 5.3 과거 길이별 진단 — 제출 기준 수치 아님

아래는 **단독 ResNet18, 과거 임계값 0.515**의 분석이다. 0.5 기준 길이별 재평가 전까지 제출 성능으로 사용하지 않는다. 발화 길이는 사후 오류 분석에만 사용했다.

| 발화 길이 | 표본 수 | Accuracy |
|---|---:|---:|
| 0–0.5초 | 8,954 | 91.29% |
| 0.5–1초 | 27,392 | 87.37% |
| 1–1.5초 | 21,931 | 88.19% |
| 1.5–3초 | 31,955 | 92.41% |
| 3–6초 | 17,750 | 96.55% |
| 6초 이상 | 3,965 | 97.96% |

0.5–1.5초가 상대적으로 약하지만 0.5초 미만의 점수는 더 높으므로, “짧을수록 항상 어렵다”는 해석은 피한다.

### 5.4 WavLM 예비 실험 — 동일한 검증 2,000개

| 방법 | 학습 발화 수 | 표본 Accuracy |
|---|---:|---:|
| WavLM 4층 + LightGBM | 10,000 | 84.30% |
| WavLM 4층 + 로지스틱 회귀 | 10,000 | 85.60% |
| WavLM 4층 + 로지스틱 회귀 | 50,000 | 87.50% |
| 기존 ResNet18 단독, threshold 0.5 | 889,358 | 91.90% |
| ResNet18 75% + 50k WavLM 25%, threshold 0.5 | 서로 다른 학습량 | 92.25% |

WavLM 결합의 이득은 동일 임계값 0.5에서 **정답 7개 증가**였다. 반복 사용한 소규모 표본의 탐색 결과이며 전체 검증의 91.419%와 직접 비교하지 않는다. 모델 구조의 공정한 우열 비교나 WavLM의 성능 한계를 입증한 실험도 아니다.

## 6. 결과 해석과 모델 유지 결정

- **깊은 모델만으로 해결되지 않았다.** ResNet34 단독은 기존 ResNet18을 넘지 못했지만 확률 결합은 일부 오답을 보완했다.
- **임계값 튜닝은 사용하지 않는다.** 주최 측 규정에 따라 Train/Validation/최종 추론 모두 0.5로 고정한다. 과거 튜닝 결과는 제출 기준에서 제외한다.
- **93%는 아직 달성하지 않았다.** 현재 102,341개 정답에서 전체 93% 이상이 되려면 최소 1,770개를 더 맞혀야 한다.
- **시간축 압축의 한계가 있다.** 전체 발화도 24프레임으로 평균 요약하므로 세부 정보가 모두 보존되지는 않는다.
- **Validation 선택 편향이 있다.** 동일 Validation에서 여러 구조·epoch·threshold·결합을 선택했다. 보고 수치는 독립 Test 성능이나 제출 완료 증명이 아니다.

### 대원 가중치 실험 결과: 현재 모델로 채택하지 않음

같은 초기 ResNet18과 학습 설정에서 Training 손실 가중치 `[1.0,1.0]`과 `[1.2,1.0]`을 비교했다. Validation에는 가중 학습이나 역전파를 적용하지 않았다. 아래 대조군·가중치 모델은 같은 임계값 0.5로 비교한다.

| 모델 | 임계값 | 전체 Accuracy | 대원 Recall | 신고자 Recall |
|---|---:|---:|---:|---:|
| 일반 학습 대조군 | 0.50 | 90.967% | 86.55% | 95.06% |
| 대원 가중치 1.2 | 0.50 | 90.873% | 88.58% | 93.00% |
| **유지할 ResNet18+34 결합** | **0.5** | **91.419%** | **86.92%** | **95.59%** |

동일 임계값에서 가중치 모델은 대원을 1,093개 더 맞혔지만 신고자를 1,198개 더 틀려 **전체 정답이 105개 감소**했다. 이번 설정에서는 대원 판단을 늘리는 trade-off가 주로 나타났으며, 전체 구분 능력 개선의 근거를 얻지 못했다. 가중치 모델을 포함한 시험 결합도 기존 91.419%를 넘지 못했다.

따라서 대원 Recall만 높다는 이유로 모델을 교체하지 않고 기존 결합을 유지한다. Dual-view 실험은 확정된 결과가 없으므로 채택 모델이나 개선 근거로 포함하지 않는다. 이후 개선은 오답 음성·발화 경계·겹침 등 원인 분석으로 가설을 세우며, 검증 오답을 Training에 편입하지 않는다.

## 7. 추론과 재현 범위

### 현재 최고 결합 결과 재현에 필요한 것

1. 동일한 `first_plus_whole` 전처리 및 uint8 양자화/역변환.
2. `mission02_next_best/best_model.pt`의 ResNet18 가중치.
3. `mission02_resnet34_v3/best_model.pt`의 ResNet34 가중치.
4. 두 모델의 신고자 확률을 50:50으로 평균한 뒤 threshold 0.5 적용.
5. 발화별 `[audio file name, startAt, endAt, speaker]` 결과 출력.
