# Mission 2 문서·결과 공개 안내

## 현재 문서 기준

- 저장소: `DCC2026-AIGO`, 문서 브랜치: `mission2/seoyun`.
- 현재 유지 모델: ResNet18+34의 확률 50:50 결합, 임계값 0.5, 전체 Validation Accuracy **91.419%**.
- [README](README.md): 전처리, 모델 선택 이유, 구조, 성능 및 한계.
- [최신 결과 보고서](results/resnet_ensemble_fixed_05.md): 클래스별 집계와 가중치 실험 후 기존 모델을 유지한 근거.
- `smallstem_resnet18/`와 그 `results/`는 **초기 90.248957% 단독 모델**의 코드·기록이다. 최신 결합 모델 코드로 오인하지 않는다.

이번 업데이트는 문서·집계와 기존 단일 모델 코드의 0.5 고정 처리를 대상으로 한다. 학습의 임계값 탐색을 제거하고 Accuracy@0.5로 선택하며, 추론·분석은 저장된 튜닝 임계값을 무시한다. 과거 학습 실행은 그대로 resume할 수 없다. 초기 실험 로그를 최신 수치로 덮어쓰거나 후속 가중치·원본 데이터를 업로드하지 않는다. 브랜치 내용을 검토한 뒤 PR로 `main`에 병합한다. 브랜치 업로드와 main 반영은 별개다.

## 공개하지 않는 파일

| 대상 | 이유 |
|---|---|
| 원본 WAV/JSON | 원본 데이터 재배포·개인정보 및 대용량 문제 |
| 발화별 매니페스트·개별 예측 배열 | 로컬 경로/개별 기록을 포함할 수 있음 |
| 대용량 특징·데이터 ZIP | 소스 문서와 별도 관리 |
| `best_model.pt`, `last_checkpoint.pt` | 별도 가중치 보관 및 제출 절차 필요 |

원본 최고 ResNet18과 ResNet34 체크포인트는 Drive 등에 보존한다. 현재 결합 모델에는 둘 다 필요하다. 가중치 실험 결과가 더 최근에 생성됐다는 이유로 기존 체크포인트를 교체하지 않는다.

## 공개 전 확인

```bash
git diff --check
git diff --stat
python mission-2/smallstem_resnet18/verify_results.py
```

기존 `verify_results.py`는 **초기 90.25% 기록의 내부 일치**를 확인하는 검사다. 최신 91.419% 모델의 추론 재실행 검사가 아니다. 최신 문서 수치는 제공된 Colab 평가 로그를 근거로 하며, 독립 Test나 제출 완료를 뜻하지 않는다.

최종 제출에는 `first_plus_whole` 전처리, 두 모델의 가중치와 결합 추론 구현, 출력 CSV 형식 및 실행 환경 검증이 별도로 필요하다.
