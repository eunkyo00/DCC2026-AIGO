# 현재 유지 모델 — ResNet18 + ResNet34, Accuracy 91.419%

## 근거와 범위

2026-10-06에 공유된 `mission02_operator_v5_comparison`의 Colab 평가 출력을 근거로 작성했다. 공식 Validation 111,947개 전체를 평가한 결과다. 이번 문서 작업에서 원본 데이터로 독립 추론하거나 Drive 체크포인트를 다시 읽은 것은 아니다. Validation은 모델·epoch·임계값 선택에도 사용되었으므로 독립 Test 결과가 아니다.

## 모델과 판정

| 구성 | 설정 |
|---|---|
| 모델 A | `mission02_next_best/best_model.pt` — ResNet18 small-stem |
| 모델 B | `mission02_resnet34_v3/best_model.pt` — ResNet34 small-stem |
| 입력 | 앞 1.5초 + 전체 발화 요약 log-Mel, `first_plus_whole`, `[1,64,48]` |
| 결합 | 두 모델의 신고자 확률을 각각 0.5 비중으로 평균 |
| 판정 | 평균 확률 ≥ 0.5이면 신고자(1), 미만이면 119대원(0) |

모델 가중치를 평균하는 것이 아니며 단일 체크포인트 성능도 아니다. 추론 시 두 모델을 함께 사용해야 한다.

## 전체 및 클래스별 성능

| 지표 | 결과 |
|---|---:|
| 전체 Accuracy | 102,341 / 111,947 = **91.419154%** |
| 119대원 Recall | 46,804 / 53,845 = **86.923577%** |
| 신고자 Recall | 55,537 / 58,102 = **95.585350%** |

혼동행렬은 행=실제, 열=예측, 순서 `[119대원, 신고자]`로 `[[46804, 7041], [2565, 55537]]`다. 대원을 신고자로 오인한 발화가 7,041개, 신고자를 대원으로 오인한 발화가 2,565개다.

주최 측 규정에 따라 최종 임계값은 0.5로 고정한다. 과거 0.52에서의 91.437%는 제출 기준 성능에서 제외한다. 기존 체크포인트의 epoch 선택에는 튜닝 점수가 사용되었으므로, 이 수치는 고정 0.5로 처음부터 학습·선택한 새 모델의 성능이 아니다. 기존 선택 이력의 허용 여부 확인 및 고정 기준 재선택/재학습은 별도 과제다.

## 가중치 모델로 교체하지 않는 이유

Training에서 대원 손실 가중치만 1.2로 높인 모델과 가중치 1.0 대조군을 비교했다. 입력 특징과 초기 모델은 동일하며 Validation은 역전파에 사용하지 않았다.

| 모델 / 임계값 | 전체 Accuracy | 대원 정답 | 신고자 정답 |
|---|---:|---:|---:|
| 대조군 / 0.5 | 90.967154% | 46,603 | 55,232 |
| 가중치 1.2 / 0.5 | 90.873360% | 47,696 | 54,034 |
| **유지 모델 A+B / 0.5** | **91.419154%** | **46,804** | **55,537** |

고정 임계값에서 대원 정답이 1,093개 늘었지만 신고자 정답이 1,198개 감소했다. 총 정답이 105개 줄었으므로 대원 Recall 상승만으로 개선이라고 판단하지 않는다. 가중치 모델을 ResNet34와 결합한 최고 시험 결과도 91.399502%(50:50, threshold 0.5)로 기존 결합보다 낮았다.

## 보존과 재현

기존 두 체크포인트 및 `mission02_features_full.zip`을 유지한다. 최신 결과 폴더라는 이유로 `mission02_operator_weighted_v5/best_model.pt`를 현재 모델로 대체하지 않는다. WavLM·Dual-view·가중치 실험 모델은 현재 결합 구성에 포함하지 않는다.

입력 전처리·모델 구조는 [Mission 2 README](../README.md)를 참고한다. 저장소의 `smallstem_resnet18/`는 초기 90.25% 실험의 기록이다. 현재 결합을 제출하려면 동일 전처리, 두 가중치, 결합 추론 코드 및 CSV 규격을 별도로 검증해야 한다. 이 보고서는 제출 완료나 93% 달성을 의미하지 않는다.
