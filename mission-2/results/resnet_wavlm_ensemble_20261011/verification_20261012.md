# 최종 선택 구성 및 효율성 확인 — 2026-10-12

## 비율과 선택 시점

현재 선택 구성은 **ResNet18 30% + ResNet34 30% + WavLM4 40%**이며 임계값은 0.5다. 세 모델 각 1/3이 아니다. 처음 37.5:37.5:25 결합을 평가한 뒤 WavLM 비중 15~40%, 이후 40~60%를 비교했다. 40%를 선택한 것은 결과를 확인한 이후다. 후보를 실행 전에 코드에 적은 것과, 최종 비율을 결과 확인 전에 확정한 것은 다르다.

1/3씩을 최종으로 선택했거나 그 비율을 결과 확인 전에 확정했다는 기록은 확인되지 않았다. 지금 1/3로 변경해도 이미 다른 실험 결과를 본 시점이므로 사전 확정 실험으로 소급 설명할 수 없다.

## 파라미터 수

| 모델 | 총 파라미터 | Fine-tuning 대상 |
| --- | ---: | ---: |
| ResNet18 small-stem | 11,169,858 | 11,169,858 |
| ResNet34 small-stem | 21,278,018 | 21,278,018 |
| WavLM4 | 38,170,066 | 14,672,170 |
| 합계 | **70,617,942** | **47,120,046** |

ResNet은 실제 로컬 checkpoint를 strict-load한 뒤 parameter tensor 수를 계산했다. WavLM은 전달된 model.py에서 계산한 구조 기준으로, Total은 공식 평가 JSON 보고값과 일치한다. WavLM 가중치 자체는 아직 수령/로드하지 않았다. WavLM head-only warmup 대상은 495,362개이며 fine-tuning은 앞 4블록 중 뒤 2블록과 head가 대상이다. 모델별로 따로 학습한 수의 합이지 앙상블 공동 학습 수가 아니다. 학습 가능한 파라미터는 추론 Active parameter와 구분한다.

## 추론 환경·batch·시간

| 실행 | 장비 | batch size | 시간 |
| --- | --- | ---: | --- |
| 비교 노트북의 ResNet18 | Tesla T4 | 128 | 타이머 기록 없음 |
| 비교 노트북의 ResNet34 | Tesla T4 | 128 | 타이머 기록 없음 |
| 팀원이 수행한 WavLM4 공식 평가 | RTX 5060 Laptop GPU 8GB | 16 | 408.609초 / 발화당 3.6500ms |
| 최종 세 모델 통합 추론 | 미측정 | 미확정 | **미측정** |

근거는 전달된 `DCC_mission2_ensemble (1).ipynb` 실행 출력과 `comparison.json`, ResNet NPZ 두 개, 로컬 비교 코드 및 WavLM `official_metrics.json`이다. 노트북에 Tesla T4가 출력되고 ResNet은 batch 128로 진행된다. WavLM 모델은 그 노트북에서 실행하지 않고 기존 확률만 읽는다. 따라서 최종 세 모델 모두 T4에서 추론했다고 기재하지 않는다. CPU 모델명은 기록되지 않았다.

WavLM 시간은 waveform shard 읽기·리샘플·forward를 포함하고 원본 WAV/JSON 읽기는 제외한다. ResNet 학습 중 평가의 별도 시간 기록과 이를 더해 최종 시간으로 사용하지 않는다. 캐시 확률 결합 시간도 모델 추론 시간이 아니다.

NPZ signature는 로컬 package.json 및 각각의 ResNet checkpoint SHA256과 일치했고, ID 순서도 aligned WavLM과 일치했다. 확률·발화 식별자·음원·가중치와 사용자 노트북은 이 공개 저장소에 업로드하지 않는다.

## 제출 전 남은 작업

최종 WavLM4 best_model.pt를 수령해 보고된 해시와 대조한 뒤, 세 로컬 가중치와 각 전처리를 사용하는 단일 inference.py를 검증해야 한다. 같은 환경에서 전체 Validation을 재추론하며 GPU/CPU, 모델별 batch size, 정밀도, 시간 측정 범위를 함께 기록한다. 재학습은 필요하지 않다. 과거 ResNet의 tuned-score 기반 checkpoint 선택 이력은 별도 규정 확인 대상으로 유지한다.
