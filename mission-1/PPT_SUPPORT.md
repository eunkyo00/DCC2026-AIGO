# Mission 1 진행 과정

## 1페이지 | 신고자 구간과 통화 단위로 평가 조건을 설정했다

**질문 | 학습에 사용할 데이터와 평가 조건을 믿을 수 있는가?**

- 119 통화에는 신고자·상담원이 함께 등장하고, 통화마다 발화 수와 길이가 다름
- 입력은 **정답 라벨의 신고자 구간**, 예측·평가는 **통화 단위**로 구성

**확인 조건과 결과**

- 파일 누락·파싱 실패 제외 → 사용 가능한 **27,985통화** 확보
- 성별 비율을 유지해 **Train 22,388 / Internal Validation 5,597통화** 분할(seed 42)
- 통화 단위 분할 → 같은 통화의 발화가 Train·Validation에 동시에 들어가는 것을 방지
- 이후 최종 성능 비교에 동일 Internal Validation 사용; 공식 Validation 결과와 구분

**품질 점검 사례 | 반복 F0 값**

- 약 329Hz 반복값 발견 → 실제 스펙트럼·합성 신호 확인 → **660Hz 톤의 반주파수 추정** 확인
- 추정값을 사람의 실제 음높이로 단정하지 않고 F0 품질 기준에 반영

**판단과 다음 질문**

- 사용 가능한 파일, 신고자 입력 구간, 통화 단위 분할을 확인한 뒤 모델 비교 진행
- **동일한 조건에서 어떤 음성 특징이 성별을 더 잘 구분하는가?**

## 2페이지 | 정확도가 낮은 MFCC도 60통화를 더 맞혔다

**질문 | 정확도가 높은 특징이 다른 특징의 정보를 모두 대체하는가?**

**실험 조건**

- 동일 Train·Internal Validation에서 음향 특징과 사전학습 특징 비교
- Wav2Vec2 본체 고정: 발화별 마지막 층 시간 평균 → 발화들을 동일 가중 평균해 통화 특징 생성
- Wav2Vec2는 **768차원 특징에 LR만 학습**, 본체 fine-tuning 미수행

| 특징·분류기 | 사용 정보 | Internal Validation 정확도 |
|---|---|---:|
| F0 + Acoustic + LR | 높낮이·음량·유성음·길이 | 91.21% |
| MFCC + RBF SVM | MFCC 통화 특징 54차원 | 95.07% |
| Frozen Wav2Vec2 + LR | 사전학습 음성 특징 768차원 | 97.25% |

**오답 비교와 판단**

- Wav2Vec2가 MFCC의 오답 **182건 교정**, 반대로 **MFCC만 맞힌 통화도 60건** 존재
- 두 모델 공통 오답 **94건** → 정확도 순위와 개별 통화의 정답 여부는 일치하지 않음
- MFCC가 보완 정보를 줄 가능성 확인 → 성능이 낮다는 이유만으로 제외하지 않고 특징 결합 실험 진행

**다음 질문**

- **MFCC만 맞힌 사례의 정보를 결합하면 개선되는가? 분류기 설정만 바꿔도 개선되는가?**

## 3페이지 | C 조정으로 45건, MFCC 추가로 35건 줄였다

**질문 | 개선은 MFCC 추가 때문인가, LR의 C 변경 때문인가?**

**실험 조건**

- 저장된 특징 재사용; Train **22,388통화**, 동일 **3-fold·8개 설정** 평가
- 규제 강도·MFCC 결합·비선형 SVM 비교; 각 fold의 Scaler는 해당 학습 통화에만 fit

| 주요 비교 설정 | Train CV 평균 정확도 | OOF 오답 |
|---|---:|---:|
| Wav2Vec2 + LR, C=1 | 97.097% | 650건 |
| Wav2Vec2 + LR, C=0.1 | 97.298% | 605건 |
| Wav2Vec2 + MFCC + LR, C=1 | 97.217% | 623건 |
| Wav2Vec2 + MFCC + LR, C=0.1 | **97.454%** | **570건** |

**효과를 나눠 해석**

- 특징 고정: Wav2Vec2 단독에서 **C=1 → 0.1** → 오답 **45건 감소**
- C 고정: **C=0.1에서 MFCC 추가** → 오답 **35건 추가 감소**
- 결합 모델의 개선을 MFCC 추가 효과 하나로 설명하지 않고, **분류기 규제 강도의 효과도 별도로 확인**

**다음 질문**

- **남은 570오답은 짧은 음성이나 높은 무음 비율로 설명되는가?**

> OOF: 각 통화를 학습에 포함하지 않은 fold 모델의 예측. 위 수치는 Train 교차검증 결과이며, 해당 후보의 새 Internal Validation 평가는 수행하지 않음.

## 4페이지 | 짧은 음성·무음만으로 남은 오류를 설명하기 어려웠다

**질문 | 짧은 음성·무음이 남은 오류의 주요 설명이 될 수 있는가?**

**분석 조건**

- Wav2Vec2 + MFCC + LR(C=0.1)의 **Train OOF 오답 570건** 분석
- 신고자 음성 길이·발화별 평균 무음 비율·발화 수·F0 지표로 구분

| 확인한 집단 | 전체 통화 | 오답 |
|---|---:|---:|
| 신고자 음성 8초 미만 | 108건 | 4건 |
| 신고자 음성 20초 이상 + 평균 무음 비율 10% 미만 | 16,587건 | 404건 |

**결과를 보고 한 판단**

- 8초 미만 집단은 **전체 570오답 중 4건** → 짧은 음성만으로 전체 오류 설명 어려움
- 길고 무음이 적은 집단에도 **404오답** → 무음 비율만으로도 설명 어려움
- **짧은 구간 삭제·무음 제거를 해결책으로 바로 채택하지 않음**
- 길이·무음의 영향을 전면 부정한 것이 아니라, 이를 전체 오류의 설명으로 삼는 근거가 부족함을 확인
- 잡음·화자 혼입·라벨 오류는 실제 원인으로 확정하지 않음

**별도 탐색 | 다른 음성 표현의 성능 비교**

- 오류 분석에서는 전처리 방향의 근거를 점검했고, WavLM 실험에서는 **사전학습 음성 표현을 바꿨을 때의 성능**을 비교
- 다음 질문: **WavLM에서는 어떤 특징 구성이 효과적인가?**

> 구성 메모: 오류 분석이 WavLM 선택의 직접 계기였다는 인과관계는 주장하지 않고, 두 활동을 별도 탐색으로 배치.

## 5페이지 | dev 정답 수가 가장 높은 1,024차원 구성을 선택했다

**질문 | 다른 음성 표현이 도움이 되는가? 더 많은 층의 정보를 써야 하는가?**

**실험 조건**

- **WavLM-Large 본체 고정**, 신고자 음성 특징 추출 후 Logistic Regression 학습
- 마지막 층 평균 vs **6·12·18·24층의 평균·표준편차** 비교
- **Train 내부 dev 4,478통화**에서 특징 2종 × C 2종 비교; fine-tuning 미수행

| 특징 구성 | 차원 | C=0.1 정답 | C=1 정답 |
|---|---:|---:|---:|
| 마지막 층 평균 | 1,024 | **4,388건** | 4,357건 |
| 여러 층 평균·표준편차 | 8,192 | 4,385건 | 4,376건 |

**결과를 보고 한 판단**

- **마지막 층 평균 + LR(C=0.1)** 선택: 비교한 4개 설정 중 dev 정답 수 최대
- 같은 C=0.1에서 **4,388 vs 4,385건**, 차이는 **3건**; 선택된 특징 차원은 8분의 1
- 선택 기준은 **관측된 dev 정답 수**이며, 작은 차이만으로 통계적 우위나 동등성을 판단하지 않음
- C=1에서는 여러 층 특징이 더 높음 → 특징 차원만으로 성능을 예측하기 어려움

> 해석 메모: 단순한 구성이 선택된 것은 결과의 특징이다. ‘성능이 동등해 단순성을 우선했다’는 사전 선택 원칙으로 바꾸어 서술하지 않음.

**다음 결정**

- 설정 확정 → 전체 Train으로 LR 재학습 → **별도의 Internal Validation** 평가
- **선택한 구성이 기존 Wav2Vec2의 오류를 실제로 얼마나 줄이는가?**

## 6페이지 | 82건 교정과 35건 신규 오류로 오답이 47건 줄었다

**질문 | 기존 오류를 얼마나 고쳤고, 새로 생긴 오류는 무엇인가?**

**평가 조건**

- 정답 신고자 구간, 동일 Internal Validation **5,597통화**
- WavLM-Large 고정 + 마지막 층 평균 + LR(C=0.1)
- 학습 대상은 LR이며 **음성 모델 본체 fine-tuning 미수행**

| 모델 | 정확도 | 오답 |
|---|---:|---:|
| Frozen Wav2Vec2 + LR | 97.25% | 154건 |
| Frozen WavLM-Large + LR(C=0.1) | **98.09%** | **107건** |

| 기존 오답 → 정답 | 기존 정답 → 오답 | 두 모델 공통 오답 | 순정답 증가 |
|---:|---:|---:|---:|
| 82건 | 35건 | 72건 | **47건** |

**결과 해석**

- 정확도 **0.84%p 향상**, 오답 **154 → 107건**, **47건 감소**
- 기존 오답 수 기준 **약 30.5% 감소**: 47 ÷ 154 × 100
- 82건을 교정했지만 35건의 신규 오류도 발생 → **교정과 신규 오류를 함께 확인**
- 공통 오답 72건 + 신규 오답 35건 = WavLM 총 오답 107건

**다음 질문**

- WavLM이 틀렸지만 Wav2Vec2가 맞힌 통화도 **35건** 존재
- **두 모델의 예측 확률을 결합하면 WavLM의 남은 오답을 줄일 수 있는가?**

> 평가 범위: 정답 신고자 구간을 이미 알고 있는 조건의 Internal Validation. 30.5%는 기존 오답 수 대비 감소율이며 통계적 유의성을 뜻하지 않음.

## 7페이지 | 전체 OOF 성능뿐 아니라 fold별 개선을 확인해 75:25를 선택했다

**질문 | 두 모델을 얼마나 섞어야 WavLM 단독보다 나아지는가?**

**실험 조건**

- 기존 특징 재사용: **WavLM 마지막 층 평균 1,024차원 / Wav2Vec2 768차원**
- 두 음성 모델 본체 고정; **WavLM LR C=0.1 / Wav2Vec2 LR C=1.0** 유지
- Train **22,388통화**, 성별 비율을 유지한 **3-fold(seed 42)**에서 OOF 확률 생성
- 각 fold의 Scaler·LR은 해당 학습 통화에만 fit; **예측 확률의 가중 평균**으로 결합

**선택 기준과 결과**

- WavLM 비중 **75% / 50%** 두 후보 비교
- 채택 조건: WavLM 단독 대비 **3개 fold 모두 하락 없음 + 전체 OOF 정확도 0.1%p 이상 개선**
- 조건 미달 시 WavLM 단독 유지; 동률이면 WavLM 비중이 높은 후보 우선

| WavLM : Wav2Vec2 | Train OOF 정확도 | Fold 1 변화 | Fold 2 변화 | Fold 3 변화 | 선택 |
|---|---:|---:|---:|---:|---|
| 100 : 0 | 98.052528% | 기준 | 기준 | 기준 | 기준 모델 |
| **75 : 25** | **98.173128%** | +0.080397%p | +0.200992%p | +0.080407%p | **채택** |
| 50 : 50 | 98.128462% | -0.066997%p | +0.254589%p | +0.040204%p | 제외 |

**결과를 보고 한 판단**

- 50:50은 전체 OOF 정확도가 올랐지만 **Fold 1에서 하락** → 사전 채택 조건 미충족
- 75:25는 **모든 fold에서 개선**, 전체 **+0.120600%p** → 채택 조건 충족
- 전체 OOF 수치만 보지 않고, **분할마다 개선이 유지되는지도 선택 기준에 반영**

**다음 결정**

- **비중 75:25 고정 → 전체 Train으로 LR 재학습 → Internal Validation 평가**
- 최종 검증 점수를 보고 비중을 다시 조정하지 않음

> Train OOF는 비중 선택용이며 독립 test가 아님. 채택 기준은 보수적인 선택 규칙으로, 통계적 유의성 검정은 아님.

## 8페이지 | 앙상블로 11건을 교정하고 4건을 새로 틀려 오답이 7건 줄었다

**질문 | Train에서 선택한 결합 비중이 Internal Validation에서도 개선되는가?**

**평가 조건**

- 기존과 동일한 **Internal Validation 5,597통화**, 정답 신고자 음성 구간 사용
- **WavLM 예측 확률 × 0.75 + Wav2Vec2 예측 확률 × 0.25**
- 두 본체는 고정하고 LR만 학습; 비중은 Train OOF에서 선택한 값으로 고정

| 모델 | 정확도 | 정답 | 오답 |
|---|---:|---:|---:|
| Frozen WavLM + LR | 98.088262% | 5,490건 | 107건 |
| **WavLM 75% + Wav2Vec2 25%** | **98.213329%** | **5,497건** | **100건** |

| WavLM 오답 → 정답 | WavLM 정답 → 오답 | 단독·앙상블 공통 오답 | 순정답 증가 |
|---:|---:|---:|---:|
| 11건 | 4건 | 96건 | **7건** |

**결과 해석**

- WavLM 단독 대비 **+0.125067%p**, 오답 **107 → 100건**으로 약 **6.54% 감소**
- 교정 11건과 신규 오류 4건을 함께 확인 → 순정답 증가 **7건**
- 고정한 확률 결합으로 추가 개선을 확인했지만, 남은 오류를 모두 해소한 것은 아님

**이번 과정에서 확인한 점**

- **정확도와 보완성은 별도 확인**: MFCC만 맞힌 60건은 특징 결합으로, Wav2Vec2만 맞힌 35건은 확률 결합 질문으로 연결
- **개선 요인과 채택 기준을 구분**: C 변경·특징 추가 효과를 나누고, 앙상블은 전체 OOF와 fold별 조건으로 선택
- **검증 전 설정 확정**: 특징·C·결합 비중을 Train에서 선택한 뒤 고정해 평가

**평가 범위와 남은 질문**

- 정답 신고자 구간을 이미 알고 있는 **기존 Internal Validation** 결과; 공식 Validation은 미사용
- 화자 구분을 포함한 end-to-end 평가나 동일 화자 분리를 보장하는 평가는 아님
- 남은 질문: 공통 오답 **96건**과 신규 오류 **4건**은 어떤 사례인가?

> 소폭 개선이 새 데이터에서도 유지되거나 통계적으로 유의하다는 결론은 내리지 않음. 반환 OOF 선택 요약은 대조했으나 raw OOF 확률·모델 파일은 없어 독립 재계산 범위에서 제외됨.
