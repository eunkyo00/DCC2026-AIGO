**질문: 증상명을 직접 말하지 않는 신고 대화에서도 환자의 증상을 구분할 수 있는가?**

- 입력: 신고자와 119대원의 전사 텍스트.
- 출력: 통화당 0~9개 증상. 하나의 통화에 여러 증상이 동시에 나타날 수 있다.
- 평가: 9개 증상의 F1을 같은 비중으로 평균한 Macro F1.
- 개발 원칙: 텍스트 외 annotation은 입력에서 제외하고, 후속 실험의 판정 임계값은 0.5로 고정.

**핵심 접근: 한국어 문맥을 학습하는 KLUE-RoBERTa와 문자 표현을 학습하는 TF-IDF를 비교·결합했다.**

### 발표자 설명

이 과제에서는 통화 전체에 하나의 정답을 붙이는 것이 아니라 각 증상의 존재 여부를 독립적으로 판단합니다. 예를 들어 구토와 복통이 동시에 있으면 두 증상을 모두 출력합니다. 단순히 증상 단어가 등장했는지만 보면 질문이나 부정 표현을 실제 증상으로 오인할 수 있습니다. 따라서 표현의 문맥을 읽는 모델을 주력으로 두고, 문자 패턴을 사용하는 모델이 보완 정보를 제공하는지도 확인했습니다. 질문·부정은 가능한 오류 메커니즘이며, 현재 결과만으로 전체 오류의 원인이라고 확정하지는 않았습니다.

## 3페이지. 문맥 표현과 문자 패턴을 서로 다른 방식으로 학습

### 슬라이드 문구

**질문: 같은 텍스트를 어떤 표현으로 바꾸어 분류할 것인가?**

| 구성 | 입력 표현 | 학습 방식 |
|---|---|---|
| KLUE-RoBERTa | 발화 사이 SEP를 넣고 앞 최대 512토큰 | 인코더와 증상별 Attention head를 함께 학습 |
| TF-IDF | 전체 전사 텍스트의 문자 2~5그램 | TF-IDF 특징과 증상별 Logistic Regression |

- Attention head는 RoBERTa를 대체하는 모델이 아니라 증상별 토큰 표현을 모으는 분류 구조.
- TF-IDF는 RoBERTa의 512토큰 제한과 달리 전체 전사를 사용.
- 두 모델의 확률을 결합한 뒤 0.5로 판정. 모델 가중치 자체의 평균은 아님.

**관측:** 같은 head 비교에서 CLS 0.610240, Mean 0.611556, Label attention 0.614364.
Attention은 CLS 대비 +0.004124였지만 오심 recall은 0.1123에 머물렀다.

**판단:** 증상별 Attention을 후속 기준으로 사용하되, head 변경만으로 오심 누락을 해결하지 못했다.

### 발표자 설명

RoBERTa는 앞뒤 토큰 관계를 반영한 표현을 만들고, 증상별 Attention head는 각 증상을 판단할 때 다른 토큰에 가중치를 줄 수 있습니다. 이것이 임상적으로 올바른 근거를 선택했다는 뜻은 아니며 Attention을 설명의 증거로 단정하지 않았습니다. TF-IDF는 문자 조각의 빈도와 희소성을 특징으로 사용합니다. 결합이 도움이 되면 두 방식이 서로 다른 오류를 일부 보완했을 가능성이 있지만, 전체 텍스트 사용과 표현 방식의 효과를 따로 분리한 실험은 아닙니다.

## 4페이지. 가중 손실은 누락을 줄였지만 오탐도 늘렸다

### 슬라이드 문구

**질문: 낮은 재현율 증상에 더 큰 학습 손실을 주면 무엇이 달라지는가?**

| 동일 조건 비교 | 일반 BCE | 가중 BCE |
|---|---:|---:|
| 전체 Macro F1 | 0.6107 | 0.6400 |
| 오심 recall | 0.1123 | 0.3608 |
| 오심 TP / FN | 75 / 593 | 241 / 427 |
| 오심 FP | 72 | 435 |

- 가중치는 내부 학습의 양성·음성 수로 계산. 예측 임계값은 계속 0.5.
- 오심 정답 탐지 166건 증가와 함께 오탐도 363건 증가.
- 전체 F1 개선과 오탐 증가를 함께 기록. 오탐이 늘었다고 학습 실패로 처리하지 않음.

**판단: 재현율 상승만으로 개선을 판단하지 않고 오탐·정밀도·F1을 함께 확인했다.**

### 발표자 설명

가중 BCE는 양성 증상을 놓치는 학습 손실을 높였습니다. 일반 BCE보다 오심 누락이 줄었지만 그 대가로 오탐이 크게 늘었습니다. 후속 실험에서는 두통·오심·전신쇠약의 양성 가중치를 1.25배 더 높였습니다. 세 seed에서 전체 F1은 조금 올랐지만 두통 F1은 모두 낮아졌습니다. 따라서 약한 증상에 가중치를 높이면 모든 지표가 좋아진다는 결론은 얻지 못했습니다.

## 5페이지. 성능이 낮은 TF-IDF도 결합에서는 도움이 됐다

### 슬라이드 문구

**질문: 단독 점수보다 실제 결합의 보완성이 중요한가?**

| 구성 | 내부 검증 Macro F1 |
|---|---:|
| Base W1 세 seed 평균 확률 | 0.645129 |
| Base 세 seed + Large, 50:50 | 0.647423 |
| 가중 TF-IDF 단독 | 0.573397 |
| RoBERTa 앙상블 80% + 가중 TF-IDF 20% | **0.650944** |

- 같은 80:20 결합에서 일반 TF-IDF는 0.648975, 가중 TF-IDF는 0.650944.
- 동일 특징·분류기·결합 비율에서 TF-IDF 학습 가중치 변경의 차이는 **+0.001969**.
- 기존 RoBERTa 앙상블에 가중 TF-IDF를 추가한 전체 차이는 **+0.003522**.
- 9개 중 7개 증상 F1 상승. 구토·오심은 하락.

**판단: 가중 TF-IDF 결합을 기준점으로 채택. 학습 가중치의 효과와 모델 추가의 효과를 구분했다.**

### 발표자 설명

초기 비가중 TF-IDF를 50:50으로 섞었을 때는 오히려 점수가 낮아졌습니다. 2-5에서는 같은 RoBERTa 앙상블과 80:20 결합 비율을 유지한 채 TF-IDF의 학습 가중치 유무를 비교했습니다. 따라서 일반 결합 대비 약 0.20%p 차이와 기존 RoBERTa 앙상블 대비 약 0.35%p 차이를 구분할 수 있습니다. 이것을 임계값 변경의 효과로 설명하지 않습니다. 개별 오류의 교정 건수는 이 발표에서 새로 계산하지 않았으므로, 어떤 사례를 보완했는지는 확정하지 않았습니다.
