# 2-9 실험: KLUE-RoBERTa Base W1 + R-Drop

## 결론

임계값 0.5의 내부 검증 Macro F1은 **0.640420**이었다. 동일 seed 42의 과거 W1 단일 모델 **0.640102**보다 **+0.000319(약 +0.0319%p)** 높았다. 상승 폭은 작고, 실행 설정이 다른 역사적 비교이므로 R-Drop 자체의 개선 효과로 단정하지 않는다. 목표 0.66에는 미달했다.

현재 최고 2-5 앙상블은 **0.650944**다. 이번 결과는 TF-IDF가 포함되지 않은 단일 모델 결과이므로 앙상블 성능을 갱신한 결과가 아니다. 새 R-Drop 모델과 기존 앙상블의 결합은 아직 평가하지 않았다.

## 조건과 변경사항

- KLUE-RoBERTa Base, 증상별 Attention head, 발화 경계 보존 First-512 입력.
- 내부 학습 23,408건, 내부 검증 5,792건. 공식 Validation은 사용하지 않았다.
- 기존 W1 가중 BCE 유지. 두통·오심·전신쇠약의 양성 가중치에 기존 1.25배 규칙 적용.
- R-Drop: 학습 시 서로 다른 dropout의 두 출력에 대한 가중 BCE 평균 + **alpha 1.0 × Bernoulli 대칭 KL 평균**.
- 평가 시 한 번의 forward, sigmoid 확률에 모든 증상 임계값 **0.5** 적용. 임계값 튜닝 없음.
- seed 42, 4에폭 최종 모델 선택, 학습률 2e-5, warmup 1,000, weight decay 0.01.
- micro batch 2 × gradient accumulation 4, FP32, gradient checkpointing 사용.
- 과거 W1은 batch 8 × accumulation 1이었다. 실질 배치 크기는 같지만 실행 방식이 달라 엄격한 단일 변인 비교는 아니다. 동일 실행 설정의 alpha 0 대조군은 이번 결과에 없다.
- 분할 SHA256: `69817218fd5677067294a6d65ec44a3d0b4d7d5d4690f71f6fa4eaea1cfcf64e`.

11,704스텝·4에폭을 완료했다. 기록된 train_runtime은 **8,822.68초(약 2시간 27분 3초)**, 평균 업데이트 속도는 1.327 step/s였다. Validation Loss는 2에폭 이후 높아졌지만 고정 임계값 Macro F1은 계속 상승했다. 두 지표는 측정 대상이 달라 함께 같은 방향으로 움직일 필요는 없다.

## 다음 판단 및 한계

기존 최고 2-5는 유지한다. 사전 제안한 기존 최고 80% + R-Drop 20% 확률 결합으로 보완 효과를 확인할 수 있으나 개선을 보장하지 않는다. 이 보고서에 그 결합 결과는 포함하지 않았다.

seed 42 한 번의 결과이며 통계적 유의성을 검정하지 않았다. 같은 내부 검증셋을 반복 사용한 탐색 결과이고 독립 테스트 성능이 아니다. TF-IDF 결합 효과와 R-Drop 효과를 구분하고 최종 후보는 별도 평가가 필요하다.
