# 낮은 recall 증상 가중치 실험

사용자가 Colab에서 실행하고 제공한 `m3_targeted_weight_results.tar.gz`의 내부 검증
결과를 정리했다. 평가 기준은 **9개 증상 Macro F1, 예측 임계값 0.5 고정**이다.
개별 예측 배열과 split manifest, 모델 가중치, 원본 통화 내용은 Git에 넣지 않았다.

## 실험 설계

- 내부 학습 23,408건, 내부 검증 5,792건; 공식 Validation 성능이 아니다.
- 모델: `klue/roberta-base`, 발화 경계 SEP + First-512, 증상별 label-attention head.
- 두 조건 모두 Weighted BCE를 사용한다. W0는 `clip(sqrt(음성/양성), 1, 3)`.
- W1은 **두통·오심·전신쇠약**의 W0 양성 가중치만 1.25배, 최대 4로 높였다.
  실제 변경값은 두통 3.00→3.75, 오심 2.785→3.481, 전신쇠약 2.124→2.655이다.
- seed 42, 4 epoch, batch 8, 학습률 2e-5, 마지막 epoch 모델, FP32, 최대 gradient norm 1.0.
- 두 실행의 초기 파라미터 해시와 분할 해시가 동일하다. 학습 설정은 출력 경로만 다르다.
- TF-IDF 확률은 앞선 성공 실험의 동일 검증 결과를 재사용했다.

## 전체 성능

| 조건 | Macro F1 | 오심 precision | 오심 recall | 오심 F1 |
|---|---:|---:|---:|---:|
| 이전 Weighted BCE 기준점 | 0.64002 | 0.3565 | 0.3608 | 0.3586 |
| W0 현재 가중치 재학습 | 0.63845 | 0.3512 | 0.3728 | 0.3617 |
| **W1 세 증상 ×1.25** | **0.64010** | 0.3256 | **0.4431** | **0.3754** |
| W0 + 고정 TF-IDF 50:50 | 0.62009 | 0.4842 | 0.1377 | 0.2145 |
| W1 + 고정 TF-IDF 50:50 | 0.62461 | 0.4684 | 0.1662 | 0.2453 |

같은 실행의 W0 대비 W1 Macro F1 상승 폭은 **0.00165**다. 이전 최고 0.64002 대비
W1은 **0.00008** 높아 사실상 동률에 가깝다. 단일 seed의 작은 차이이므로 안정적인
성능 향상이나 목표 0.65 달성으로 해석하지 않는다. 50:50 TF-IDF 앙상블은 이번에도
RoBERTa 단독보다 낮다.

## 증상별 변화

| 증상 | W0 F1 | W1 F1 | 변화 |
|---|---:|---:|---:|
| 고열 | 0.6589 | 0.6673 | +0.0085 |
| 구토 | 0.6049 | 0.6081 | +0.0032 |
| **두통** | **0.5243** | 0.5140 | **−0.0103** |
| 복통 | 0.7852 | 0.7889 | +0.0038 |
| 어지러움 | 0.6624 | 0.6719 | +0.0095 |
| 열상 | 0.8862 | 0.8830 | −0.0032 |
| **오심** | 0.3617 | **0.3754** | **+0.0137** |
| **전신쇠약** | **0.5750** | 0.5677 | **−0.0073** |
| 호흡곤란 | 0.6876 | 0.6845 | −0.0030 |

세 목표 증상의 recall은 모두 상승했다. 두통 0.5387→0.5525,
오심 0.3728→0.4431, 전신쇠약 0.6102→0.6299다. 다만 두통과 전신쇠약은
precision 하락으로 F1이 낮아졌다. 오심은 실제 양성 668건 중 TP가 249→296,
FN이 419→372로 개선됐지만, FP도 460→613으로 늘고 precision은 0.3512→0.3256으로
내려갔다. 오심의 예측 양성 건수는 709→909다.

## 학습 경과와 판단

| epoch | W0 Macro F1 | W1 Macro F1 |
|---|---:|---:|
| 1 | 0.6313 | 0.6381 |
| 2 | 0.6379 | 0.6370 |
| 3 | 0.6349 | 0.6372 |
| 4 | 0.6384 | 0.6401 |

실험은 미리 정한 마지막 epoch와 0.5 임계값으로 평가했다. W1은 오심을 덜 놓치지만
전체 개선 폭이 매우 작고 두통·전신쇠약 F1에는 불리했다. 따라서 **W1을 확정된 새
기준 모델로 채택하기보다**, W0/W1을 동일 조건의 여러 seed로 반복해 평균과 변동을
확인하는 것이 다음 단계다. 검증 결과를 보고 이 분할에서 배율을 계속 조정하면
내부 검증에 과적합될 수 있다.
