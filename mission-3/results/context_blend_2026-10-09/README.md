# 2-8 실험: 기존 최고 앙상블과 문맥 모델 결합

## 결론

2-5 예측 확률 80%와 2-7 문맥 모델 예측 확률 20%를 결합한 내부 검증 Macro F1은 **0.650801**이었다. 기존 최고 2-5의 **0.650944**보다 **0.000144(약 0.0144%p)** 낮았다. 개선을 확인하지 못했으므로 기준 모델은 2-5로 유지한다. 목표 0.66에는 0.009199(약 0.9199%p) 부족하다.

## 실험 조건

- 입력 결과: `m3_2_5_tfidf_weight_results.tar`, `m3_2_7_base_seed42_results.tar`.
- 평가: 기존과 동일한 내부 검증 5,792건, 증상 9개 Macro F1.
- 결합: `p = 0.8 * p_2_5 + 0.2 * p_2_7`. 결합 비율은 실행 전에 고정했다.
- 분류 임계값: 모든 증상 **0.5**, 임계값 튜닝 없음.
- 2-5: 다중 seed Base·Large 앙상블 80% + 가중 문자 TF-IDF 20%.
- 2-7: KLUE-RoBERTa Base + 증상별 Attention head + W1 가중 BCE, seed 42. 통화 앞·뒤 최대 512토큰 창의 logit 평균.
- 이번 실험은 저장된 확률을 결합했으며 모델을 새로 학습하지 않았다.
- 분할 SHA256: `69817218fd5677067294a6d65ec44a3d0b4d7d5d4690f71f6fa4eaea1cfcf64e`.

## 해석 및 한계

두통·호흡곤란 등 일부 증상은 개선됐으나 오심·구토 등의 하락이 이를 상쇄했다. 특히 오심은 TP 263→262, FP 467→483, FN 405→406으로 변해 precision과 recall이 모두 낮아졌다. 문맥 모델을 더하는 것만으로 오심의 오류가 해결되지는 않았다.

전체 차이는 작으며 통계적 유의성을 검정하지 않았다. 이 결과로 문맥 처리 전반이 효과 없다고 단정할 수 없다. 동일 내부 검증셋을 반복 사용한 탐색 결과이고, 공식 Validation 또는 독립 테스트 성능이 아니다. 후속 실험에서도 2-5를 기준으로 비교하되 최종 후보는 독립 평가가 필요하다.
