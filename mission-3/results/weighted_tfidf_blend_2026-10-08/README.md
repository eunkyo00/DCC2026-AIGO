# 2-5 실험: 가중 TF-IDF와 RoBERTa 앙상블 결합

사용자가 Colab에서 제공한 `m3_2_5_tfidf_weight_results.tar`를 분석했다. 내부 검증 5,792건의 9개 증상 Macro F1이며 **임계값은 0.5 고정**이다. 공식 Validation 결과가 아니다.

## 실험 조건

- B는 2-4의 Base 3개 seed 평균과 Large seed 42를 50:50으로 결합한 앙상블이다. 기존 B의 예측을 재사용했다.
- TF-IDF는 내부 train 23,408건에만 fit했다. 전체 발화 텍스트를 사용하며 문자 2~5 gram, min_df 2, 최대 특징 150,000, sublinear TF를 적용했다.
- 증상별 Logistic Regression: C=2, solver=liblinear, max_iter=1000, seed 42.
- T0는 비가중, T1은 학습 데이터에서 계산한 양성 가중치 `clip(sqrt(negative/positive),1,3)`를 사용했다. 나머지 TF-IDF·분류기 설정은 동일하다.
- 결합 비율은 **B 80% + TF-IDF 20%**로 실행 전에 고정했다. 주 비교는 T0 결합과 T1 결합이다. 임계값·결합 비율 탐색은 하지 않았다.
- 제공된 네 예측 배열에서 F1을 재계산해 저장된 지표와 일치함을 확인했다.

## 전체 결과

| 조건 | Macro F1 | B 대비 |
|---|---:|---:|
| B, 기존 2-4 앙상블 | 0.647423 | — |
| T0, 일반 TF-IDF 단독 | 0.470607 | −0.176816 |
| T1, 가중 TF-IDF 단독 | 0.573397 | −0.074025 |
| B 80% + T0 20% | 0.648975 | +0.001552 |
| **B 80% + T1 20%** | **0.650944** | **+0.003522** |

가중 TF-IDF 결합은 기존 B보다 **약 0.35%p**, 일반 TF-IDF 결합보다 **약 0.20%p** 높다. 내부 검증 Macro F1 0.65를 넘었지만 목표 0.66까지 **0.009056(약 0.91%p)** 남았다. TF-IDF 단독 성능이 RoBERTa 앙상블보다 낮아도 결합에서는 도움이 됐다.

## 증상별 변화

| 증상 | 기존 B F1 | 가중 TF-IDF 결합 F1 |
|---|---:|---:|
| 고열 | 0.6639 | 0.6708 |
| 구토 | 0.6258 | 0.6235 |
| 두통 | 0.5239 | 0.5262 |
| 복통 | 0.7925 | 0.8002 |
| 어지러움 | 0.6777 | 0.6838 |
| 열상 | 0.8838 | 0.8914 |
| 오심 | 0.3815 | 0.3763 |
| 전신쇠약 | 0.5836 | 0.5873 |
| 호흡곤란 | 0.6942 | 0.6991 |

기존 B 대비 7개 증상의 F1은 상승했고 구토·오심은 하락했다. 오심 precision은 0.3341 → 0.3603으로 높아졌지만 recall은 0.4446 → 0.3937로 떨어졌다. 따라서 이번 전체 점수 상승을 오심 누락 문제의 해결로 해석하면 안 된다.

T1 단독은 T0 단독보다 높은 점수를 얻었다. 다만 일반 TF-IDF 결합이 가중 결합보다 두통·전신쇠약·호흡곤란 F1은 높았다. 증상별 최고 조합을 검증셋에서 사후 선택하지 않고 사전 고정한 두 결합을 모두 보고한다.

## 해석과 한계

반복 사용한 내부 검증셋에서 얻은 탐색 결과다. 개선폭이 작으므로 독립 평가 없이 일반화 성능 향상이나 목표 달성을 확정하지 않는다. 최종 후보 선택 뒤 별도 평가가 필요하다.

최종 결합은 개별 Base 모델 각각 2/15, Large 0.4, 가중 TF-IDF 0.2의 비율이다. 새 데이터 추론에는 Base 3개·Large 1개의 가중치와 TF-IDF vectorizer·9개 분류기, 동일 전처리가 필요하다. 결과 TAR에는 이 모델들이 포함되지 않았다.
