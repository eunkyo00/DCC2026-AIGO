# 2-4 실험: 고정 비율 다중 seed 및 Base–Large 앙상블

사용자가 Colab에서 실행한 `m3_2_4_fixed_ensemble_results.tar`를 분석했다. 내부 검증 5,792건의 9개 증상 Macro F1이며 **임계값은 0.5 고정**이다. 공식 Validation 결과는 아니다.

## 실험 조건

- 모든 구성 모델은 W1 Weighted BCE와 증상별 attention head, 발화 경계 보존 First-512를 사용한 최종 4 epoch 모델이다.
- A (주 실험): KLUE-RoBERTa Base seed 42·123·2026의 예측 확률을 각각 1/3로 평균했다.
- B (추가 탐색): A의 확률과 KLUE-RoBERTa Large seed 42 확률을 50:50으로 평균했다. 개별 Base 가중치는 각각 1/6, Large는 1/2이다.
- 결합 비율은 실행 전에 고정했다. 임계값·결합 비율 탐색이나 새 모델 학습은 하지 않았다. TF-IDF는 포함하지 않는다.
- 예측 배열에서 A/B의 F1을 다시 계산하여 저장된 지표와 일치함을 확인했다. 노트북은 원본 모델 간 검증 행 순서·정답·타깃 순서·분할·손실 가중치 일치를 검사한다.

## 전체 결과

| 조건 | Macro F1 | Base seed 42 대비 |
|---|---:|---:|
| Base seed 42 | 0.640102 | — |
| Base seed 123 | 0.639002 | −0.001100 |
| Base seed 2026 | 0.640935 | +0.000833 |
| Large seed 42 | 0.637518 | −0.002584 |
| A: Base 3개 동일 비율 | 0.645129 | +0.005028 |
| **B: A + Large 50:50** | **0.647423** | **+0.007321** |

B는 A보다 0.002293 높고, 가장 높은 단일 모델인 Base seed 2026보다 0.006488 높다. Base seed 42 대비 상승 폭은 약 **0.73%p**다. 목표 0.66까지는 **0.012577(약 1.26%p)** 남았다.

Large 단독 점수는 낮았지만 결합 시에는 도움이 됐다. 이는 모델들의 예측 차이가 결합에 유용했다는 결과이며, Large 단독 학습 자체의 우수성을 뜻하지 않는다. 세 seed는 앙상블 구성원이며 앙상블 실험을 독립적으로 세 번 반복한 것이 아니다.

| 증상 | Base seed 42 F1 | A F1 | B F1 |

| 고열 | 0.6673 | 0.6663 | 0.6639 |
| 구토 | 0.6081 | 0.6131 | 0.6258 |

| 복통 | 0.7889 | 0.7926 | 0.7925 |

| 열상 | 0.8830 | 0.8810 | 0.8838 |

| 전신쇠약 | 0.5677 | 0.5795 | 0.5836 |

B는 Base seed 42 대비 고열을 제외한 8개 증상의 F1이 높다. 구토·전신쇠약에서 상승 폭이 크다. 오심은 precision 0.3256 → 0.3341, recall 0.4431 → 0.4446으로 소폭 개선됐다. TP는 296 → 297, FP는 613 → 592, FN은 372 → 371이다. 오심 F1은 여전히 0.3815로 낮아 남은 개선 과제다.

## 해석과 제약

고정 임계값 조건에서 이전 구성 모델들보다 높은 내부 검증 성능을 얻었다. 다만 같은 내부 검증셋을 여러 실험에 반복 사용했고 B는 추가 탐색 조건이므로, 독립 최종 성능이나 통계적 유의성을 주장하지 않는다. 최종 후보를 정한 뒤 별도 평가가 필요하다.

새 데이터에 B를 적용하려면 Base 3개와 Large 1개의 가중치, 동일 전처리와 확률 평균 추론 코드가 필요하다. 단일 모델보다 저장 공간과 추론 연산량이 늘어난다. 현재 결과 TAR는 기존 예측 배열을 결합한 자료로 모델 가중치를 포함하지 않는다.
