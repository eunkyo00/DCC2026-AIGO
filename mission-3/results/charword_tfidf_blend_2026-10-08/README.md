# 2-6 실험: 문자+단어 TF-IDF 결합

사용자가 Colab에서 실행한 `m3_2_6_charword_results.tar`의 내부 검증 결과다. 검증 5,792건, 9개 증상 Macro F1을 **임계값 0.5 고정**으로 평가했다. 공식 Validation 결과는 아니다.

기존 2-5의 가중 문자 TF-IDF에 단어 1~2그램을 추가했다. RoBERTa 앙상블 B와 TF-IDF의 결합 비율은 **80:20**으로 유지했다. 단어 특징 추가에 따른 전체 정규화도 적용되므로, 두 조건은 TF-IDF 특징 표현에서 차이가 있다. 새 RoBERTa 학습은 하지 않았다.

| 조건 | Macro F1 |
|---|---:|
| B 단독 | 0.647423 |
| 2-5: B + 가중 문자 TF-IDF | **0.650944** |
| 2-6: B + 가중 문자·단어 TF-IDF | 0.650060 |

2-6은 2-5보다 **0.000884(약 0.088%p) 낮다**. 새 TF-IDF 모델 단독도 0.562364로 기존 가중 문자 TF-IDF 단독 0.573397보다 낮다. 두 앙상블의 점수를 저장된 예측 배열에서 다시 계산해 확인했다. 목표 0.66에 도달하지 못했으므로, 현재 내부 검증 기준점은 **2-5의 0.650944**로 유지한다.

두통 F1은 0.5262 → 0.5271로 소폭 올랐지만 오심은 0.3763 → 0.3719, 전신쇠약은 0.5873 → 0.5863으로 떨어졌다. 단일 분할에서 확인한 결과이므로 단어 특징이 항상 불리하다고 일반화하지 않는다.
